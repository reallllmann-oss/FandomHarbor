# Documentation Application Boundary

Future read-only online browsing entry for approved project documentation, including PRD, Product Phase Roadmap, decisions and version records.

The Markdown files under the root `docs/` and `.ai/` directories remain the source of truth. This application may render approved content but must not create a second editable copy or expose private operational/security documents without authorization.

No application has been scaffolded and no functionality exists in Phase 0.6.
