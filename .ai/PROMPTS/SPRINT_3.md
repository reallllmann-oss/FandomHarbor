# Legacy Sprint 3 — Publish and Read a Durable Text Work

Status: Superseded as a product-stage roadmap. Candidate work is now separated across Phase 2 — Publishing and Phase 3 — Reading.

Outcome: an Author publishes a versioned text work through a pen name and a Reader reads it comfortably.

Envelope: pen names, works, chapters, TipTap document schema/editor, preview/publish, immutable revisions, diff/restore, reading page, chapter navigation and reading preferences.

Exit requires ownership/RLS negative tests, revision recovery, sanitized rendering, mobile reading and accessibility acceptance.
