# Contract Registry

`API_SPECIFICATION.md` is the current semantic catalog. Future contracts receive stable IDs and runtime Zod ownership.

Contract types include resource projections, mutation inputs/results, cursor pagination, errors, upload intents, event payloads and webhook payloads. TypeScript types are inferred from runtime schemas where possible; duplicate handwritten contracts are prohibited.

Admin P0 Site Copy uses the implemented provider-neutral and Repository contract in [`SITE_COPY_CONTRACT.md`](SITE_COPY_CONTRACT.md).

Use `CONTRACT_TEMPLATE.md` before implementation.
