# Accessibility Rules

Status: Proposed

Target: WCAG 2.2 AA for Reader, Author, Admin and Docs surfaces.

- Logical headings, landmarks and skip navigation.
- Visible focus, predictable tab order and full keyboard operation.
- Persistent labels; error summary linked to invalid fields.
- 44×44px target for primary touch interactions.
- No color-only meaning; icons have names or are hidden when decorative.
- Dialog focus trap/restore and non-modal alternatives where appropriate.
- Respect zoom, text scaling, contrast preferences and reduced motion.
- TipTap controls expose semantic names, active states and keyboard access.
- Automated checks supplement manual keyboard and screen-reader review.

Accessibility is an acceptance condition, never postponed polish.
