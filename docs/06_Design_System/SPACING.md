# Spacing System

Status: Proposed

Base unit: 4px. Approved scale: 0, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64 and 80px.

- Inline icon/text: 4–8px.
- Field label/control/help relationships: 8–12px.
- Related form fields: 16–24px.
- Form sections: 32–48px.
- Major page regions: 48–80px where viewport permits.
- Touch hit areas remain at least 44×44px even when visual content is smaller.

Components use semantic spacing roles. Negative margins and arbitrary values require documented layout necessity.
