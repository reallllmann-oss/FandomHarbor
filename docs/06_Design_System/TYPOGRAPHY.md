# Typography System

Status: Proposed

- UI base: 16px / 1.5.
- Reading default: 18px / approximately 1.78; user-adjustable without breaking layout.
- System default reading text does not fall below 17px on mobile.
- Metadata target: 13–14px minimum with verified contrast.
- Reading measure: 68ch default, approximately 52–80ch supported.
- Type scale: 12, 14, 16, 18, 20, 24, 30, 36 and 48.
- UI uses a language-capable system sans initially; reading offers a language-capable serif/sans choice.

Semantic roles—not page-local font sizes—define display, heading, body, reading body, label, metadata, code and caption. Chinese, Latin, mixed-language, long titles, ruby/footnotes and browser font scaling require validation.
