# Motion System

Status: Proposed

Durations: instant 0ms, fast 120ms, normal 180ms and deliberate 240ms. Motion explains state, hierarchy or location; it never delays reading.

- Enter, exit and move use shared easing roles.
- Reading views avoid parallax, autoplay and attention loops.
- Loading feedback starts promptly and does not rely on endless decorative animation.
- Reduced-motion mode removes nonessential transform and cross-fade effects.
- Destructive outcomes are confirmed through content/state, not animation alone.
