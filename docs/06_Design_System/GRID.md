# Grid System

Status: Proposed

- General content shell: maximum approximately 1280px with responsive gutters.
- Reading column: measure-based, not viewport-based.
- Long-form/editor forms: comfortable single-column width around 720px unless structure requires more.
- Admin desktop: 12-column grid with explicit sidebar/content ownership.
- Mobile: single-column flow by default; nested grids must preserve reading and form order.

Grid order must match semantic/keyboard order. Desktop sidebars may collapse or move below content, but critical rating/warning and action context cannot disappear.
