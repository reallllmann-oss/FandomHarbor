# Dark Mode

Status: Proposed

Dark mode is a semantic theme, not mechanical color inversion.

- Preserve reading contrast without pure-white glare or crushed black surfaces.
- Re-test all semantic colors, focus rings, borders, code/diff, ratings and warnings.
- User theme preference supports light, dark and system.
- Images and user content are not color-inverted.
- Elevation relies on surface steps/borders as well as shadow.
- Theme switching must not flash gated content or reset reading position/preferences.

Final dark token values require accessibility and long-session reading review.
