# Responsive Rules

Status: Proposed

Starting breakpoints: 640, 768, 1024, 1280 and 1536px. They are implementation starting points; content failure determines final behavior.

- Design core Reader and Author journeys from 320px logical width upward.
- Desktop adds supporting context, not longer prose lines.
- Navigation never requires hover.
- Metadata wraps/collapses without hiding rating or warning information.
- Tables become labeled cards or controlled horizontal regions on small screens.
- Safe areas, browser zoom, 200% text scaling and virtual keyboards must not block primary actions.
