# Elevation System

Status: Proposed

Levels: `flat`, `raised`, `sticky`, `overlay` and `modal`.

- Prefer border, surface contrast and spacing before shadow.
- Cards are normally flat or lightly raised.
- Sticky navigation uses separation only while overlapping content.
- Dropdowns/dialogs use standardized overlay shadows and backdrops.
- Elevation never substitutes for accessible focus or selection state.
- Z-index uses semantic layers: base, sticky, dropdown, overlay, modal, toast.

Components cannot invent numeric z-index escalation.
