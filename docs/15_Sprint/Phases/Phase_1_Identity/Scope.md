# Phase 1 Scope

## In scope

- Supabase Auth
- Invitations/redemptions
- Memberships/role grants
- RLS test matrix
- audit baseline
- Web/Admin access shells

## Out of scope

- 作品发布、阅读互动、标签搜索和举报业务

Scope changes require written review, affected architecture/data/API/UI updates and revised acceptance/risks before implementation.
