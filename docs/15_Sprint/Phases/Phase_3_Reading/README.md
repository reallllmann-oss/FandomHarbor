## Stage model

- Phase 3A — Beta Blocking：只处理 Beta 上线阻塞，是唯一阻塞上线的部分。
- Phase 3B — Beta Operations：最小邀请码运营能力，不阻塞 Beta 上线。
- Phase 3C — Beta Polish：上线后的体验优化，全部可延期。
- Release Readiness：独立于 Phase 3，负责 Release Candidate、Go / No-Go、上线检查和回退准备。
