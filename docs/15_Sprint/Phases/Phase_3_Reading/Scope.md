# Phase 3 Scope

## In scope

- Phase 3A：Beta 基线、生产环境验真、远程注册/登录/Studio/Reader 链路和 P0 修复。
- Phase 3B：Author Public Profile、Follow / Unfollow 与 Invitation Relationship Foundation。
- Phase 3C：Search MVP、Browse Experience 与 SEO Foundation。
- 独立 Release Readiness：Release Candidate、Go / No-Go、上线检查、回退文档和 Checklist。

## Out of scope

- 完整数据分析后台。
- 复杂推荐、评论、通知、社区或收费系统。
- 复杂邀请关系可视化、图表和统计平台。
- 大规模重构、新技术栈、新设计系统或多语言。
- 未经独立授权的正式发布或流量切换。

Scope changes require written review, affected architecture/data/API/UI updates and revised acceptance/risks before implementation.
