# Product Phases and Engineering Sprints

- `ROADMAP.md` is the Product Phase Roadmap.
- `Phases/` contains the mandatory seven-document package for each Phase.
- `SPRINT_TEMPLATE.md` is the global fallback; each Phase also owns its contextual Sprint template.
- `Release_Readiness/` contains the independent V1 Beta release audit, release checklist and browser QA checklist.

Phase describes product evolution and acceptance. Sprint describes bounded engineering execution inside one Phase. Never use Sprint numbers as product-stage names.
