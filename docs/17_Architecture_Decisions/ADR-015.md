# ADR-015 — Database and Interface Traceability Registries

- Date: 2026-06-28
- Status: Accepted blueprint decision; implementation remains gated by Phase 0.6 approval
- Related .ai decisions: D-021

## Context

Tables, migrations, RLS policies and interfaces become unsafe when their ownership, contracts and review requirements are scattered or implicit.

## Decision

Every database object belongs to the applicable ERD/Migration/Policies/RLS/Seed/Indexes/Lifecycle records. Every interface belongs to REST, ServerActions, Realtime, Webhooks or Events and references Errors/Contracts.

## Consequences

Traceability adds documentation work before implementation but substantially reduces unowned schema changes, permission gaps and transport mixing.

## Review trigger

Review when automated schema/contract documentation can preserve the same ownership and approval guarantees.
