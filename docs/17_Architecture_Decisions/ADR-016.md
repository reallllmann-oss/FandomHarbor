# ADR-016 — AI Tech Lead Behavior and Phase Documentation

- Date: 2026-06-28
- Status: Accepted blueprint decision; implementation remains gated by Phase 0.6 approval
- Related .ai decisions: D-023

## Context

AI assistance optimized only for code volume can silently replace architecture, ignore future phases and let documentation drift. Product Phases also need durable boundaries beyond one roadmap paragraph.

## Decision

Make `.ai/AI_BEHAVIOR.md` mandatory startup context. Every Product Phase owns README, Goals, Scope, Acceptance, Risks, Sprint Template and Retrospective.

## Consequences

AI behavior and Phase planning become reviewable contracts. The document count grows, so links, templates and change discipline are mandatory.

## Review trigger

Review when collaboration practices change or repeated maintenance evidence shows the package is too heavy without improving decisions.
