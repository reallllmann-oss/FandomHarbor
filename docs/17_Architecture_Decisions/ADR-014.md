# ADR-014 — UI, Design System and Component Separation

- Date: 2026-06-28
- Status: Accepted blueprint decision; implementation remains gated by Phase 0.6 approval
- Related .ai decisions: D-020; DD-005

## Context

Visual experience, reusable design tokens and component implementation contracts have different review cycles. Combining them makes UI intent dependent on component details and encourages local token forks.

## Decision

`05_UI` owns experience direction, `06_Design_System` owns reusable tokens/layout/accessibility rules, and `07_Component` owns implementation contracts.

## Consequences

Changes have clear ownership and shared rules remain reusable. Maintainers must update cross-layer references when a decision affects more than one layer.

## Review trigger

Review only if the separation creates measured duplication or a future design tooling workflow requires a different authoritative format.
