## 2. Key Decisions

- Reading Page visual direction is **Private Literary Reading Space**.
- Apple Books is used as an abstract reference for calm reading environment, focused typography and minimal interaction.
- Fandom Harbor must preserve literary warmth, author connection, story atmosphere and private reading continuity.
- Reading Page should feel like entering a quiet story space, not reading a webpage article.
- Typography, space, background, navigation and interaction density must all protect prose focus.
- Chapter transition is part of reading continuity, not only navigation utility.
- Reading Page must avoid blog, news, CMS, social platform, forum and dashboard visual categories.

## 3. Design Impact
