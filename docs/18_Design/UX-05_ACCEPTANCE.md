## 2. Key Decisions

- Recommended Homepage visual direction is **Quiet Editorial Harbor**.
- Homepage should combine editorial whitespace, literary typography, restrained navigation, text-led story preview and calm closing rhythm.
- Reference 1 contributes whitespace and brand feeling.
- Reference 3 contributes work presentation logic.
- Reference 4 contributes sparse navigation logic.
- Reference 5 contributes calm ending rhythm.
- Reference 2 contributes tonal restraint but not page structure.
- Homepage must not become a work list, magazine subscription page, blog index, retail hero, public ranking page, SaaS landing page or CMS dashboard.
